# IBM-House-price-prediction-project

Machine learning project for predicting house prices using housing-related features and multiple machine learning and deep learning models.

## Project Overview

This project focuses on predicting house prices using historical housing data and machine learning techniques.

The project follows a complete machine learning workflow including data preprocessing, exploratory data analysis, feature selection, model training, evaluation, model comparison, and prediction analysis.

## Problem Statement

Accurately predicting house prices is important for buyers, sellers, and real estate businesses.

House prices can vary based on different factors such as location, housing characteristics, number of rooms, population, income, and the age of the house. This project uses housing-related features to predict the median house value.

## Objective

The main objectives of this project are:

* Predict house prices.
* Analyze the distribution and patterns of house prices.
* Perform exploratory data analysis and data visualization.
* Select important features for prediction.
* Train and compare multiple machine learning and deep learning models.
* Evaluate model performance using MAE, RMSE, and R² Score.
* Select the best-performing model.
* Compare actual and predicted house prices.
* Analyze prediction errors.

## Dataset

### Dataset Description

The project uses dataset **from the kaggle** containing information about houses and housing-related features.

* Target variable: **median_house_value**
* Target meaning: **Median value of houses**

The dataset is used to train machine learning models to predict house prices based on different housing characteristics.

### Important Features

* longitude
* latitude
* housing_median_age
* total_rooms
* total_bedrooms
* population
* households
* median_income
